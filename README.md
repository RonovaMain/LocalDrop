# LocalDrop

Локальный HTTP-сервер для мгновенного запуска статических веб-проектов и SPA в домашней или офисной Wi-Fi сети. Написан на Python и [Flet](https://flet.dev), работает на **Android**, **Windows** и **Linux**.

## Как это работает

Загрузите в приложение `.html`-файл, `.zip`-архив или папку с проектом. LocalDrop распакует файлы, найдёт `index.html` и добавит сайт в библиотеку. После запуска сервера проект станет доступен с любого устройства в вашей Wi-Fi сети по локальному IP или через QR-код.

## Возможности

- **Импорт и распаковка:** поддержка `.html`, `.zip` и папок (включая drag-and-drop на десктопе). Защита от zip-slip и zip-бомб, корректная работа с кириллицей в Windows-архивах (`cp866`). Автоматический поиск `index.html` (включая `dist/index.html` для сборок Vite/React).
- **Полноценный HTTP-сервер:** корректные MIME-типы для ES-модулей, CSS, шрифтов, медиа, JSON и WASM. Поддержка CORS, `Range`-запросов (перемотка видео/аудио), кэширования (`ETag`/`304`), чистых URL (`/about` → `about.html`) и кастомных страниц `404.html`.
- **Поддержка SPA:** маршруты без расширения файла автоматически отдают `index.html`, а запросы к отсутствующим статическим ресурсам возвращают `404`.
- **Live Reload:** отслеживание изменений файлов через SSE. При правках в CSS стили обновляются без перезагрузки страницы, в остальных случаях страница обновляется целиком.
- **Анализ проекта:** подсчёт веса и количества файлов по типам, поиск пустых ссылок (`href="#"`) и комментариев `TODO`.
- **Управление:** тёмная тема, одновременный запуск нескольких сайтов на разных портах, генерация QR-кодов, статистика и лог HTTP-запросов в реальном времени.

## Ограничения

- **Фоновый режим на Android:** сервер работает внутри основного процесса приложения. Чтобы система не выгружала его при погасшем экране, в интерфейсе предусмотрена блокировка сна (wake lock). Для импорта на Android рекомендуется использовать `.zip` вместо папок из-за ограничений Scoped Storage.
- **Сеть и безопасность:** раздача идёт по HTTP без шифрования — используйте приложение только в доверенных Wi-Fi сетях (в настройках сайта доступ можно ограничить только текущим устройством).
- **Web API:** из-за работы по HTTP в браузерах на других устройствах недоступны API, требующие HTTPS (Service Workers, камера, геолокация). На самом устройстве-хосте они работают через `http://127.0.0.1:<порт>/`.
- **Порты:** поддерживаются порты от `1024` и выше.
